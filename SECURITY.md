# Security

Report vulnerabilities privately to lanxing@phronesis.studio. Include the affected
version, platform, impact and a minimal redacted reproduction. Do not disclose
credentials, signing keys, private context, Feed payloads or customer identities
in public issues, pull requests or logs. Coordinate public disclosure with the
maintainers. Only publisher-signed official releases use the official update channel.
Code licensing does not grant hosted API access.
